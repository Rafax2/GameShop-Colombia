# GameShop Colombia

Tienda online de videojuegos construida con Next.js, TypeScript y Tailwind CSS.

## Scripts

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Estructura

- `app/` — rutas (inicio, tienda, detalle de juego, carrito, checkout)
- `components/` — UI reutilizable
- `data/` — catálogo de juegos, categorías y plataformas
- `lib/` — utilidades, carrito y formato de precios
- `public/` — imágenes, iconos y logo
